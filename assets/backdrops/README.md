Drop backdrop images here (jpg, jpeg, png or webp) and they appear in the editor's
Look panel automatically. No code change needed.

Guidance:
- 1920x1080 or larger. Images are scaled to cover the frame and centre-cropped.
- Keep the middle calm: the recording sits on top of it with an inset, so busy
  centres fight the content.
- The filename becomes the label, so `deep-space.jpg` shows as "Deep Space".

## The set that ships

Five: `warm-dune`, `cold-harbour`, `deep-space`, `linen-bone`, `blueprint-grid`. All
five are drawn by `tools/make-backdrops.js` rather than photographed, so the set carries
no licence and needs no attribution: no stock image, no rendered device, nothing taken
from anyone. `node tools/make-backdrops.js` writes the same bytes again, so a backdrop
is changed by changing its recipe.

`PROMPTS.md` is the brief the set was designed against and is still the brief for
anything added to it, however it is made.
